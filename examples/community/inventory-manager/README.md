# 📦 Inventory Manager

Stock tracking for small shops and cooperatives

## Features
- Barcode scanning
- Low stock alerts
- Sales reports
- Supplier management

## Data Model
- **Product**
- **Stock**
- **Sale**
- **Supplier**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a stock tracking for small shops and cooperatives"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add inventory-manager
frontier compile app.frontier --target native
./app
```
