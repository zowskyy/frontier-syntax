# 🎉 Event Planner

Community event organization and attendance

## Features
- RSVP tracking
- Task assignment
- Budget management
- Reminders

## Data Model
- **Event**
- **Attendee**
- **Task**
- **Budget**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a community event organization and attendance"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add event-planner
frontier compile app.frontier --target native
./app
```
