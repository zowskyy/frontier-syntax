# 💰 Community Ledger

Micro-loan and savings group management

## Features
- Loan tracking
- Payment schedule
- Group savings
- Transparency reports

## Data Model
- **Member**
- **Loan**
- **Payment**
- **Savings**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a micro-loan and savings group management"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add community-ledger
frontier compile app.frontier --target native
./app
```
