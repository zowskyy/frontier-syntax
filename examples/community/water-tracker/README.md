# 🚰 Water Tracker

Water pump maintenance and repair tracking

## Features
- GPS tracking
- Photo capture
- Service scheduling
- Offline storage

## Data Model
- **Pump**
- **Location**
- **ServiceRecord**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a water pump maintenance and repair tracking"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add water-tracker
frontier compile app.frontier --target native
./app
```
