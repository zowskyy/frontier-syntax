# 🏥 Clinic Records

Patient records and appointment management for rural clinics

## Features
- Patient search
- Visit history
- Prescription tracking
- Privacy-focused

## Data Model
- **Patient**
- **Visit**
- **Prescription**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a patient records and appointment management for rural clinics"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add clinic-records
frontier compile app.frontier --target native
./app
```
