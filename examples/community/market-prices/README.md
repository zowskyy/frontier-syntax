# 🌾 Market Prices

Crop price comparison and market finder for farmers

## Features
- Price comparison
- Market locator
- Price history
- Offline caching

## Data Model
- **Crop**
- **MarketPrice**
- **Vendor**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a crop price comparison and market finder for farmers"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add market-prices
frontier compile app.frontier --target native
./app
```
