# 📚 School Attendance

Student attendance and grade tracking for village schools

## Features
- QR check-in
- Attendance reports
- Grade tracking
- Parent notifications

## Data Model
- **Student**
- **Class**
- **Attendance**
- **Grade**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a student attendance and grade tracking for village schools"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add school-attendance
frontier compile app.frontier --target native
./app
```
