# 📋 Field Survey

Offline data collection for community surveys

## Features
- Custom forms
- GPS tagging
- Photo attachments
- CSV export

## Data Model
- **Survey**
- **Question**
- **Response**
- **Location**

## Quick Start

### Install via Lighthouse
1. Open Lighthouse
2. Type: "Build me a offline data collection for community surveys"
3. Lighthouse will generate a customized version

### Install via Frontier CLI
```bash
frontier add field-survey
frontier compile app.frontier --target native
./app
```
