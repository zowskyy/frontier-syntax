# Contributing to Frontier

Thank you for your interest in Frontier! We welcome contributions from everyone.

## Code of Conduct

Frontier is committed to providing a welcoming and inclusive environment. Please read our Code of Conduct before contributing.

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run verification: `cargo test && python3 scripts/verify_all.py`
5. Submit a pull request

## What We Need

- Code (new features, bug fixes)
- Documentation (improving guides, adding examples)
- Community (helping others, promoting Frontier)
- Business (connecting with potential users)

## Rewards

- Contributors are recognized in the project
- Top contributors become maintainers
- Community members get early access to new features
