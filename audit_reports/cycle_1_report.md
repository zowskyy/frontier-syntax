## Specification Summary

### Keywords (13, all reserved)

`let`, `fn`, `return`, `if`, `else`, `true`, `false`, `null`, `int`, `float`, `bool`, `string`, `void`

### Identifier Constraint

`[A-Za-z_][A-Za-z0-9_]*` — ASCII only. No Unicode homoglyphs.

### String Constraint

Double quotes (`"`) only. Single quotes (`'`) are **illegal**.

### Prefix-Disjointness (§9)

- **PD-1:** Multi-char operators matched by longest-prefix rule (`==` before `=`, `<=` before `<`).
- **PD-2:** Keywords match only when NOT followed by `[A-Za-z0-9_]`. Thus `if` is keyword but `iff` and `ifoo` are identifiers.
- **PD-3:** `iff` is **banned** as a keyword (not in keyword set).
- **PD-4:** All 13 keywords are pairwise non-prefix.
- **PD-5:** Single-char operators use lookahead for multi-char forms.

### Encoding

UTF-8 with **NFC normalization applied before lexing**.

### Lexer Engine

**re2c v3.1** — guaranteed O(n) time complexity.
