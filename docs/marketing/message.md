# Frontier Messaging

## Taglines

- "The Future of Computing"
- "Build Anything. Prove Everything."
- "Universal Programming for Everyone"

## Elevator Pitch

"Frontier is the first universal programming language that anyone—from a child to a CTO—can use to build verified, secure, and scalable software. It provides the simplest interface in the world: describe what you want, and Frontier builds it."

## Key Messages

1. **Accessible:** Anyone can use it, regardless of background
2. **Verified:** Mathematically proven correct code
3. **Powerful:** Replaces everything that came before
4. **Universal:** Migrates any legacy system
5. **Future-proof:** Post-quantum, decentralized, self-hosting

- Enterprise CTOs
- Startup CTOs
- Individual Developers
- Hobbyists
