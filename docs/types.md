# Types

| Type | Description |
|------|-------------|
| `int` | 64-bit signed integer |
| `float` | IEEE 754 double |
| `bool` | Boolean (`true` / `false`) |
| `string` | UTF-8 string (double-quoted) |
| `void` | No return value |

## Annotations

- `?` — Optional type (nullable)
- `!` — Required type (non-null assertion)
