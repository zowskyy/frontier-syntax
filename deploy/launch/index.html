Frontier Syntax

v2.0 — WASM-native compiler with empirical release gates

Frontier Syntax is a research language and compiler toolchain with wasmtime-verified codegen, native self-host probes, and automated release readiness auditing.

Quick start

git clone https://github.com/zowskyy/frontier-syntax.git
cd frontier-syntax
cargo test --lib
python3 scripts/release_readiness.py --audit
