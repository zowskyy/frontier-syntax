# Frontier v2.0: The Future of Computing

Today, we are proud to announce the launch of Frontier v2.0 — the first universal programming language that anyone, from a child to a CTO, can use to build verified, secure, and scalable software.

## What is Frontier?

Frontier is a complete computing stack that includes:

1. **A universal programming language** with a natural language interface
2. **A verified compiler** that proves code correctness
3. **A migration tool** that migrates any legacy system in hours
4. **A runtime** that runs on any hardware, from bare metal to cloud
5. **An ecosystem** of verified packages and tools

## Why Frontier?

- **Accessible:** Anyone can use it, regardless of background
- **Verified:** Mathematically proven correct code
- **Powerful:** Replaces everything that came before
- **Universal:** Migrates any legacy system
- **Future-proof:** Post-quantum, decentralized, self-hosting

## Get Started Today

```bash
curl -sSL frontier.dev/install | sh
frontier migrate --input /path/to/your/project --output /path/to/migrated
```
