## [0.1.0] - 2026-08-08

### Added

- **SLICE 0** — Repository skeleton, fixtures, plugin manifest, documentation stubs
- **SLICE 1** — Pydantic configuration with workspace, model, and network settings
- **SLICE 2** — Workspace guard with path traversal and symlink protection
- **SLICE 3** — Append-only SQLite audit log with correlation IDs
- **SLICE 4** — Model provider abstraction (Mock, Ollama, LlamaCpp)
- **SLICE 5** — Structured model output parser (FINAL, TOOL_CALL, etc.)
- **SLICE 6** — Tool registry with risk metadata and handlers
- **SLICE 7** — Policy engine with default-deny authorization
- **SLICE 8** — Transactional edit engine with hash verification
